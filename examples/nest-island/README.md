# Nest Island 🪺

A tiny crescent island curled around a quiet lagoon, like a bird's nest in the sea: a sandy beach, a little village of four houses, a lily pond, tree groves, flowers, stones and two wooden piers.

**Open it:** start the NestST editor, click **Open project** and choose this `nest-island` folder. Paint on it as much as you like (maybe make a copy first so the original stays tidy).

**Tiles:** one 48 × 32 map with a single layer, `Ground`, drawn only with the 32 built-in tiles that the palette shows (ids 1–32), so you can keep editing it by hand. Every cell is filled; nothing is empty.

It was drawn with NestST's own data model: a small script built the map with `@nestst/core` and saved it with `saveProject`, so these are exactly the files the editor writes.
