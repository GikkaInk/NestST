# NestST — исследование (рабочее название, не окончательное)

Дата: 2026-10-18. Статус: предварительное. Факты отделены от допущений.

## 1. Среда разработки (проверено)
- CachyOS, 12 ядер, 15 ГБ RAM, GTX 1660 Ti.
- Установлены: Node 24, Python 3.14, Godot 4.7.2, Flatpak. Не установлены: Rust/Cargo, Go.

## 3. Решение по архитектуре
Godot отклонён пользователем. Кандидат: собственный движок и редактор на TypeScript + PixiJS (рисование) + Tauri (оболочка Linux).
Плюсы: игры запускаются в браузере, лёгкое расширение сообществом, гибкий UI редактора.
Минусы: нужен Rust для Tauri (не установлен), нативная скорость ниже Rust/C++ (для 2D RPG достаточно).
Отклонено: Rust+Bevy (дорогой UI редактора, медленная сборка), рендер с нуля.
Статус: ожидает подтверждения пользователя.

## 4. ИИ-генерация изображений
### Официальный OpenAI (по [странице модели](https://developers.openai.com/api/docs/models/gpt-image-2))
- Модель `gpt-image-2`, снимок `gpt-image-2-2026-04-21`; эндпоинты generations, edits, batch; Responses API не поддерживается.
- Цена противоречива между источниками ($4/$15 против $8/$30 за 1 млн токенов). Прозрачность и размеры для `gpt-image-2` не подтверждены (в руководстве описаны для моделей 2.5). Нужна верификация организации.

### Сторонний OpenAI-совместимый шлюз (измерено 2026-10-18)
- `GET /v1/models` совместим с форматом OpenAI; владелец моделей `token-router` (маршрутизатор). Условия использования не изучены.
- Тариф `gpt-image-2.5` (скриншот пользователя): $0,20 вход / $0,40 выход за 1 млн токенов.
- Две пробные генерации (`docs/assets/icon1.png`, `icon2.png`):
  - ~2058 выходных токенов, ~51 с, **≈ $0,0008 за картинку**.
  - Параметры `quality: low` и `size: 1024x1024` проигнорированы (ответ: `auto`, 1254×1254).
  - В ответе модель названа `gpt-image-2-codex`, хотя запрашивалась `gpt-image-2.5`.
  - Прозрачный фон: углы alpha=0 на обеих картинках (в первой без запроса). Проверка на одном примере.
  - Стиль: «под пиксель-арт», края сглажены, не точная пиксельная сетка.
- Не проверено: `/v1/images/edits`, согласованность стиля, надёжность и условия сервиса.
- Вывод: провайдер — заменяемый модуль с настраиваемыми адресом, ключом и моделью; приложение само приводит размер и проверяет прозрачность.

## 5. Монетизация (предварительно)
- Модель: бесплатное ядро (MIT) + платная ИИ-подписка «без своего ключа» + облако (сборки, хостинг) позже + магазин расширений ещё позже.
- Рыночные ориентиры: ИИ-сервисы для ассетов $10–50/мес ([Ludo.ai](https://ludo.ai/pricing)); Steam 30%, itch.io по умолчанию 10% ([обзор](https://fungies.io/steam-revenue-share-explained/)).
- Риски: зависимость от одного шлюза, неизвестные условия перепродажи, правила Steam/itch.io по ИИ-контенту (не проверено).
- Статус: ожидает подтверждения пользователя.
